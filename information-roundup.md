## 13. Smart dispatchers (Tags 6, 7, 8 — what they pull at runtime)

These tags read existing page content rather than holding static data. Listed here for completeness.

### Tag 6 — Smart Content (fires per content type)
Reads from each page's:
- Body class (`page-node-type-page`, `page-node-type-article`, `page-node-type-news`, `page-node-type-blog`, `page-node-type-event`)
- `<link rel="canonical" href="...">`
- Meta tags: `og:title`, `og:description`, `og:image`, `og:updated_time`
- For event pages: the Drupal SmartDate field `.field--name-field-event__date` (start + end times), `.field--name-field-event__location-name`, `.field--name-field-event__location-address`

Emits appropriate schema (Article / NewsArticle / BlogPosting / SportsEvent / WebPage). For events, automatically detects which campus by matching location name against "pajulahti" / "kisakallio" / "makelanrinne".

Homepage gets a fallback image hardcoded: `pajulahti_ilmakuva_ns_web_0869.jpg`.

### Tag 7 — Smart Section (fires per URL pattern)
URL-based dispatch:
- `/meista/yhteystiedot` → ContactPage
- `/meista/*` → AboutPage
- `/ryhmat-ja-leirit/*` → TouristTrip + Product (Group/youth camps)
- `/koulutus/koulutukset/*` (non-known programs) → generic Course
- `/vapaa-aika/aktiviteetit/*` → TouristAttraction
- `/yritykset/*` → Service
